Click in a line and type. The page is shown the way it reads: headings in heading type, **bold**
and *italic* in their own look, `code` in a box, ~~crossed out~~ when it is done with. The marks
that make them stay in the text but step back, so the words come first.

## Blocks

A page is a column of blocks. This is a paragraph. Below are the other kinds.

> A quote: notes should outlive the app that wrote them.

- A bullet list
- with a second item
  - and one nested under it
1. A numbered list
2. counts by itself

| Key | What it does |
|---|---|
| Enter | A new line below. On an empty list item it ends the list |
| Backspace at the start | Joins the line to the one above |
| Tab, Shift+Tab | More or less indent on a list item |
| Up, Down | Move to the line above or below |
| Escape | Leave the line |
| Ctrl+S | Save now. The page saves itself anyway |

## Equations

Type TeX between dollar signs: $E = mc^2$ inline, or a block of its own:

$$
\int_0^1 x^2 \, dx = \tfrac{1}{3}
$$

NoteCraft draws fractions, roots, sums, integrals, brackets and Greek letters itself. Anything it
does not know stays visible as text rather than disappearing.

## The ribbon

**Home** has the marks and the blocks, a Styles gallery and the Tags gallery. **Insert** has
tables, pictures, files, links, equations, diagrams and today's date. **View** has full page,
search, rule lines, zoom, the theme and the page source.

## The page source

The file behind this page is one click away: the `< >` button beside the page. What you type in
either one lands in the file. Use it for anything the editor does not do yet.
