Diese Seite ist eine **HTML**-Datei. Die anderen Seiten in diesem Abschnitt sind **Markdown**-Dateien. Beide werden gleich bearbeitet, und auf der Seite sind sie nicht zu unterscheiden; das Format steht oben rechts neben dem Speicherstatus.

| Format | Datei | Gut für |
| --- | --- | --- |
| HTML, die eingebaute Vorgabe | index.html | Reiches Layout und Seiten, die von woanders kommen |
| CommonMark + GFM | index.md | Saubere Unterschiede und Zusammenführungen, und das Lesen der Datei für sich |

## Wo die Wahl getroffen wird

1. Das Format, das Sie beim Anlegen der Seite wählen.
2. Das nächstgelegene Format, das auf einem Abschnitt, einer Gruppe oder einem Notizbuch darüber gesetzt ist.
3. Die globale Einstellung, das Feld **Standardformat** in der oberen Leiste.
4. Die eingebaute Vorgabe, HTML.

Eine Einstellung ändert nur neue Seiten. Vorhandene Seiten behalten ihr Format, das am Dateinamen zu erkennen ist, also braucht es zum Lesen einer Seite nie eine Einstellung.

## Sehen Sie sich den Quelltext dieser Seite an

Klicken Sie auf die Schaltfläche `< >` neben der Seite. Der Kopf der Datei trägt die Kennung und die Daten der Seite als `<meta name="notecraft:...">`-Tags; eine Markdown-Seite trägt dasselbe in ihrem Vorspann. NoteCraft bearbeitet nur, was innerhalb von `<body>` steht.
