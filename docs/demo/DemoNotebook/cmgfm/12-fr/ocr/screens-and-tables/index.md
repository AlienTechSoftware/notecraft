Cette page fait partie de la démonstration OCR. Statut : **MVP**.

La capture d'écran d'une application est aussi du texte. Ici, l'éditeur de requêtes se lit ligne par ligne, donc une recherche d'un nom de colonne ou de mesure trouve cette page.

![Un éditeur de requêtes dans une application de données, avec une requête DAX qui résume les ventes par région de magasin, et son tableau de résultats](assets/ocr-dax-query.png)

Un tableau se lit comme des lignes de texte. Ses cellules se trouvent par la recherche, mais la structure du tableau n'est pas encore conservée.

![Un tableau de données de commandes avec numéro, dates, client, magasin, produit, quantité et prix unitaire](assets/ocr-data-grid.png)
