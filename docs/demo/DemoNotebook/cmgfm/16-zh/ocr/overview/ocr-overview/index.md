本页是 OCR 演示的一部分。状态为 **MVP，进行中**：印刷文字已可用，其余部分属于后续阶段。

NoteCraft 读取图片中的印刷文字，并把结果保存在图片旁边。搜索会再次找到这些文字，因此收据照片上的一个词会带你找到它所在的页面。

一切都在本设备上运行。图片、它的文字和搜索索引都保存在你的笔记本文件夹和应用自己的数据中。任何内容都不会发送到服务器。
