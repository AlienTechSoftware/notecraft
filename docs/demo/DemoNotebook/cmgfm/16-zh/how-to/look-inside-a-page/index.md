很多笔记应用把整本笔记放在一个二进制文件里，用文本编辑器打开只能看到乱码。NoteCraft 的页面是一个装着普通文件的文件夹，代码视图会把这个文件夹一个文件一个文件地展示给你。现在就试试：点击这个页面旁边的 `< >` 按钮。

## 你会看到什么

左侧是**本页的文件**：先是页面自己的文件 `index.md`，然后是文件夹里的其他东西。页面上没有任何地方用到的文件会标上*页面未使用*。右侧是你选中的文件。你正在读的就是这个页面，所以查看器显示的是它自己的文本。

页面文件会完整显示：它的**头部**（页面的 ID、标题、顺序、日期和设置）和下面的**正文**。全部都可以编辑。再按一次同一个按钮即可关闭此视图，页面会根据您写的内容重新绘制。

| 文件 | 查看器显示什么 | 能输入吗 |
|---|---|---|
| 页面文件 `index.md` 或 `index.html` | 头部，以及保存时的原样正文 | 全部都可以 |
| 绘图 `ink.svg` | SVG 文本，以及笔自己的读数 | 可以，要小心 |
| 图片 | 图片 | 不能 |
| 其他文本 | 它的文本 | 不能 |
| 其他任何文件 | 名称、大小和类型 | 不能 |

超过 256 KB 的文件只显示开头部分，并会说明这一点。

## 它让你看到什么

- 用方框排版的页面，每个方框外面都有一个带 `class="nc-box"` 的 `div`。
- 绘图是一个文件 `ink.svg`，页面的文本用一行把它的名字写出来。
- 标签和链接都是普通文本。

没有任何东西是隐藏的：页面显示的内容，都在这个文件夹的某个文件里。
