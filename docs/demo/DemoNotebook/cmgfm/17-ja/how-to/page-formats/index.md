このページは **HTML** ファイルです。このセクションのほかのページは **Markdown** ファイルです。どちらも同じように編集でき、ページ上では見分けがつきません。形式は右上、保存状態の横に表示されます。

| 形式 | ファイル | 向いているもの |
| --- | --- | --- |
| HTML、組み込みの既定 | index.html | 豊かなレイアウト、ほかから来たページ |
| CommonMark + GFM | index.md | きれいな差分とマージ、ファイル単体での読みやすさ |

## どこで決まるか

1. ページを作るときに選んだ形式。
2. その上のセクション、グループ、ノートブックに設定された一番近い形式。
3. 全体の設定。上部バーの**既定の形式**。
4. 組み込みの既定、HTML。

設定が変えるのは新しいページだけです。すでにあるページは自分の形式を保ち、それはファイル名から分かるので、ページを読むのに設定は要りません。

## このページのソースを見る

ページの横の `< >` ボタンを押してください。ファイルの先頭にはページの識別子と日付が `<meta name="notecraft:...">` タグとして入っています。Markdown ページは同じものをフロントマターに持ちます。NoteCraft が編集するのは `<body>` の中だけです。
