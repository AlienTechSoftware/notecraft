## 테마

오른쪽 위의 해 또는 달이 테마 선택기를 엽니다. 밝은 테마와 어두운 테마, 각각 일곱 가지 강조색, 모두 14가지입니다. 견본을 클릭하면 그 모드가 선택됩니다. 견본 아래의 스위치를 켜면 NoteCraft가 다시 시스템의 밝기 설정을 따릅니다.

모든 테마의 모든 색은 배경과의 대비를 테스트로 확인하므로, 읽을 수 없는 글자를 보여 주는 테마는 없습니다.

## 노트북과 섹션의 색

노트북, 섹션 그룹, 섹션을 오른쪽 클릭하고 **색**을 고르세요. 아홉 가지 색이 아이콘과 행의 가장자리에 보입니다. 이 노트북의 그룹마다 색이 하나씩 있습니다.

## 페이지 자체의 보기

| 페이지 옆 버튼 | 동작 |
|---|---|
| `< >` | 페이지의 파일을 코드 보기로 열기 |
| 돋보기 | 모든 페이지 검색 |
| 화살표 | 전체 페이지. 다시 누를 때까지 노트북 목록이 물러남 |

**보기**에서는 페이지 뒤의 줄선, 확대, 페이지 제목 숨기기도 고를 수 있습니다. 줄선과 확대는 기억됩니다.

## 떠난 곳에서 다시 열기

NoteCraft는 닫을 때 보던 페이지를, 그 위의 섹션을 펼친 채로 다시 엽니다.

## 디스크의 설정

이 모든 것은 노트북 바깥의 작은 설정 파일 몇 줄입니다. 그래서 노트북이 한 사람의 창 설정을 다른 사람의 동기화 폴더로 옮기는 일은 없습니다.
