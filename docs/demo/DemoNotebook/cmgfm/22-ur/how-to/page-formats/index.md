یہ صفحہ ایک **HTML** فائل ہے۔ اس سیکشن کے باقی صفحے **Markdown** فائلیں ہیں۔ دونوں ایک ہی طرح ایڈٹ ہوتے ہیں اور صفحے پر ان میں فرق نہیں کیا جا سکتا؛ فارمیٹ اوپر محفوظ ہونے کی حالت کے ساتھ دکھتا ہے۔

| فارمیٹ | فائل | کس کے لیے اچھا |
| --- | --- | --- |
| HTML، بلٹ ان ڈیفالٹ | index.html | بھرپور لے آؤٹ، اور کہیں اور سے آئے صفحے |
| CommonMark + GFM | index.md | صاف فرق اور ضم، اور فائل کو اکیلے پڑھنا |

## انتخاب کہاں ہوتا ہے

1. وہ فارمیٹ جو آپ صفحہ بناتے وقت چنتے ہیں۔
2. اس کے اوپر کسی سیکشن، گروپ یا نوٹ بک پر سیٹ کیا گیا قریب ترین فارمیٹ۔
3. عمومی ترتیب، اوپر کی پٹی میں **ڈیفالٹ فارمیٹ** کا خانہ۔
4. بلٹ ان ڈیفالٹ، HTML۔

ترتیب صرف نئے صفحے بدلتی ہے۔ جو صفحے آپ کے پاس ہیں وہ اپنا فارمیٹ رکھتے ہیں، جو فائل کے نام سے ظاہر ہے، اس لیے صفحہ پڑھنے کے لیے کوئی ترتیب درکار نہیں۔

## اس صفحے کا ماخذ دیکھیں

صفحے کے ساتھ `< >` بٹن دبائیں۔ فائل کا سر صفحے کی شناخت اور تاریخیں `<meta name="notecraft:...">` ٹیگوں میں رکھتا ہے؛ Markdown صفحہ یہی اپنے فرنٹ میٹر میں رکھتا ہے۔ NoteCraft صرف `<body>` کے اندر کا حصہ ایڈٹ کرتا ہے۔
