Щелчок правой кнопкой показывает, что можно сделать дальше, и набор пунктов зависит от места щелчка. Сочетания клавиш позволяют перемещаться между страницами без мыши.

![Меню страницы в навигаторе, с пунктом «Заблокировать только для чтения»](assets/page-menu.png)

| Где щёлкнуть правой кнопкой | Что предлагает меню |
|---|---|
| Страница в навигаторе | Новая страница, Добавить подстраницу, Заблокировать только для чтения или Разблокировать, Переименовать, Переместить или копировать, Копировать ссылку на страницу, Открыть папку, Версии страницы, Удалить |
| Текст страницы | Вставить, Вырезать и Копировать, вставки (таблица, ссылка, формула, дата и время, рисунок, файл), а также Заблокировать только для чтения или Разблокировать. Заблокированная страница предлагает только Разблокировать |
| Пустое место в списке страниц | Новая страница, а также Заблокировать только для чтения или Разблокировать для открытой страницы |
| Пустое место в навигаторе | Новый блокнот, Открыть папку, Показать папку блокнотов, а также Заблокировать только для чтения или Разблокировать для открытой страницы |

## Блокировка страницы

«Заблокировать только для чтения» хранит блокировку внутри самой страницы, поэтому она переносится вместе со страницей при копировании или синхронизации её папки. Заблокированная страница сохраняет заголовок и текст: поле заголовка не принимает ввод, а изменения отклоняются. Чтобы снова редактировать, выберите «Разблокировать» в том же меню.

## Перемещение

- Ctrl+Page Up и Ctrl+Page Down: предыдущая или следующая страница в списке страниц.
- Alt+влево и Alt+вправо или кнопки «назад» и «вперёд» мыши: переход назад и вперёд по открытым страницам.
- Поиск по всем страницам: поле в правом верхнем углу находит слова во всех страницах. Enter открывает выбранный результат.
