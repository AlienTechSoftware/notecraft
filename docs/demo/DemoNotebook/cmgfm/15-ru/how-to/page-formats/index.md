Эта страница файл **HTML**. Остальные страницы этого раздела файлы **Markdown**. Оба редактируются одинаково, и на странице их не различить; формат показан справа вверху, рядом с состоянием сохранения.

| Формат | Файл | Хорош для |
| --- | --- | --- |
| HTML, встроенный по умолчанию | index.html | Богатой вёрстки и страниц, пришедших откуда-то ещё |
| CommonMark + GFM | index.md | Чистых различий и слияний, и чтения файла самого по себе |

## Где делается выбор

1. Формат, выбранный при создании страницы.
2. Ближайший формат, заданный у раздела, группы или записной книжки выше.
3. Общая настройка, поле **Формат по умолчанию** в верхней панели.
4. Встроенное значение, HTML.

Настройка меняет только новые страницы. Уже имеющиеся сохраняют свой формат, который виден по имени файла, поэтому для чтения страницы настройка никогда не нужна.

## Посмотрите исходник этой страницы

Нажмите кнопку `< >` рядом со страницей. Заголовок файла несёт идентификатор и даты страницы в тегах `<meta name="notecraft:...">`; страница Markdown несёт то же в своей преамбуле. NoteCraft редактирует только то, что внутри `<body>`.
