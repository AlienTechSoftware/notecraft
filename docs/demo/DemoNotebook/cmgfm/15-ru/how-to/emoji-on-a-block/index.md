В левом верхнем углу каждого блока есть небольшой знак **+**. Нажмите на него, чтобы открыть сетку эмодзи.
Выберите эмодзи, и он появится рядом с **+**. Чтобы убрать эмодзи, нажмите на него в блоке.

## Попробуйте

1. Нажмите **+** в левом верхнем углу этого блока.
2. Прокрутите сетку и выберите эмодзи. Он появится рядом с **+**.
3. Нажмите на этот эмодзи в блоке. Он исчезнет.
