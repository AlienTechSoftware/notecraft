Эта страница входит в демонстрацию OCR. Статус: **MVP**.

Снимок экрана приложения тоже является текстом. Здесь редактор запросов читается строка за строкой, поэтому поиск по имени столбца или меры находит эту страницу.

![Редактор запросов в приложении для данных с запросом DAX, который суммирует продажи по регионам магазинов, и таблица результатов](assets/ocr-dax-query.png)

Таблица читается как строки текста. Её ячейки находятся поиском, но структура таблицы пока не сохраняется.

![Таблица заказов с номером, датами, клиентом, магазином, товаром, количеством и ценой за единицу](assets/ocr-data-grid.png)
