Esta página es un archivo **HTML**. Las demás páginas de esta sección son archivos **Markdown**. Ambos se editan igual y no se distinguen en la página; el formato aparece arriba a la derecha, junto al estado de guardado.

| Formato | Archivo | Bueno para |
| --- | --- | --- |
| HTML, el predeterminado | index.html | Diseño rico, y páginas que vienen de otro sitio |
| CommonMark + GFM | index.md | Diferencias y fusiones limpias, y leer el archivo por sí solo |

## Dónde se decide

1. El formato que eliges al crear la página.
2. El formato más cercano fijado en una sección, grupo o cuaderno por encima.
3. El ajuste global, la caja **Formato predeterminado** de la barra superior.
4. El predeterminado incorporado, HTML.

Un ajuste cambia solo las páginas nuevas. Las que ya tienes conservan su formato, que se ve en el nombre del archivo, así que nunca hace falta un ajuste para leer una página.

## Mira el código de esta página

Pulsa el botón `< >` junto a la página. La cabecera del archivo lleva la identidad y las fechas de la página como etiquetas `<meta name="notecraft:...">`; una página Markdown lleva lo mismo en su cabecera inicial. NoteCraft solo edita lo que hay dentro de `<body>`.
