# ページを書く

行をクリックして入力します。ページは読むときの姿で表示されます。見出しは見出しの書体で、**太字**と*斜体*はそれぞれの見た目で、`コード`は枠の中に、~~取り消し線~~は済んだものに。それらを作る記号は本文に残りますが後ろに下がり、言葉が前に出ます。

## ブロック

ページはブロックの縦の列です。これは段落です。以下はほかの種類です。

> 引用：ノートは、それを書いたアプリより長生きすべきだ。

- 箇条書きのリスト
- 二つ目の項目
  - その下に入れ子になった項目
1. 番号付きリスト
2. 番号は自動で付きます

| キー | 動作 |
|---|---|
| Enter | 下に新しい行。空のリスト項目ではリストを終える |
| 行頭での Backspace | 上の行とつなげる |
| Tab、Shift+Tab | リスト項目の字下げを深く、浅く |
| 上、下 | 上の行、下の行へ移動 |
| Escape | 行から抜ける |
| Ctrl+S | 今すぐ保存。ページはどのみち自動保存される |

## 数式

ドル記号の間に TeX を書きます。行内なら $E = mc^2$、独立したブロックなら：

$$
\int_0^1 x^2 \, dx = \tfrac{1}{3}
$$

NoteCraft は分数、根号、総和、積分、括弧、ギリシャ文字を自分で描きます。知らないものは消えずにテキストのまま見えます。

## リボン

**ホーム**には記号とブロック、スタイルギャラリー、タグギャラリーがあります。**挿入**には表、画像、ファイル、リンク、数式、図、今日の日付があります。**表示**には全画面ページ、検索、罫線、ズーム、テーマ、ページのソースがあります。

## ページのソース

このページの背後にあるファイルはクリックひとつで開けます。ページの横の `< >` ボタンです。どちらに入力してもファイルに届きます。エディターがまだできないことはそこで行ってください。
