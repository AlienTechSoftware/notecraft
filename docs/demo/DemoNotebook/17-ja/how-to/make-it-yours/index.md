# 自分好みにする

## テーマ

右上の太陽または月でテーマ選択が開きます。ライトとダーク、それぞれ 7 つのアクセント色、合わせて 14 種類です。見本をクリックするとそのモードになります。見本の下のスイッチで、NoteCraft は再びシステムのライト／ダーク設定に従います。

どのテーマのどの色も背景との対比をテストで確かめているので、読めない文字を出すテーマはありません。

## ノートブックとセクションの色

ノートブック、セクショングループ、セクションを右クリックして**色**を選びます。9 色がアイコンと行の端に表示されます。このノートブックのグループにはそれぞれ色が付いています。

## ページ自身の表示

| ページの横のボタン | 動作 |
|---|---|
| `< >` | ページのファイルをコードビューで開く |
| 虫眼鏡 | すべてのページを検索 |
| 矢印 | 全画面ページ。もう一度押すまでノートブック一覧が退きます |

**表示**ではページの背後の罫線、ズーム、ページタイトルの非表示も選べます。罫線とズームは記憶されます。

## 前回の場所で開く

NoteCraft は閉じたときのページを、その上のセクションを展開した状態で開き直します。
