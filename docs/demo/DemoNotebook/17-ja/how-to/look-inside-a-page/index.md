多くのノートアプリは、ノートブック全体を 1 つのバイナリファイルに入れていて、テキストエディターで開いても意味のない文字が並ぶだけです。NoteCraft のページは普通のファイルが入ったフォルダーで、コードビューはそのフォルダーをファイルごとに見せてくれます。今すぐ試してください。このページの横にある `< >` ボタンを押します。

## 見えるもの

左側は**このページのファイル**です。最初にページ自身のファイル `index.md`、そのあとにフォルダー内のほかのものが並びます。ページのどこからも使われていないファイルには*ページでは使われていません*と表示されます。右側は選んだファイルです。いま読んでいるのがこのページなので、ビューアーにはこのページ自身のテキストが表示されます。

ページのファイルは丸ごと表示されます。**ヘッド**（ページの ID、タイトル、順序、日付、設定）と、その下の**本文**です。すべて編集できます。同じボタンをもう一度押すとビューが閉じ、書いた内容からページが描き直されます。

| ファイル | ビューアーの表示 | 入力できるか |
|---|---|---|
| ページのファイル `index.md` または `index.html` | ヘッドと、保存されたままの本文 | すべて |
| 描画 `ink.svg` | SVG のテキストとペン自身の読み取り値 | はい、注意して |
| 画像 | 画像 | いいえ |
| ほかのテキスト | そのテキスト | いいえ |
| それ以外 | 名前、サイズ、種類 | いいえ |

256 KB を超えるファイルは最初の部分だけを表示し、その旨を表示します。

## 分かること

- ボックスで配置したページには、各ボックスを囲む `class="nc-box"` の `div` があります。
- 描画は `ink.svg` というファイルで、ページのテキストが 1 行でその名前を挙げています。
- タグとリンクは普通のテキストです。

隠れているものはありません。ページに表示されるものは、このフォルダーのどれかのファイルに入っています。
