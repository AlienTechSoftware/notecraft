# 行にタグを付ける

タグは行に意味を与えます。やるべきこと、大事なこと、答えを待つ問い。行をクリックし、**ホーム**のタグ欄を選びます。同じタグをもう一度選ぶと外れます。

## ToDo

- [ ] このノートブックを開く
- [x] ようこそのページを読む
- [ ] 上のボックスをクリックしてチェックを入れる

ToDo の行はタスクリストの項目で、どの Markdown リーダーでも読めます。

## ほかのタグ

#important 出発は土曜ではなく金曜。

#question 電車は空港に止まる？

#idea チケットはメールではなくページに入れておく。

#remember 予約番号は添付ファイルの中。

NoteCraft は単語の代わりにマークを描きますが、ファイルにあるのは単語です。だからノートはどのエディターでも読め、ターミナルから検索できます。タグに見えるだけの語、たとえば後ろに空白のない #ideas はそのままです。

## まだないもの

独自のタグと、タグ付きの行をすべて集める一覧ページはまだ作られていません。「タグを探す」ボタンがそう告げます。
