# תמונות וקבצים

גררו קובץ ממנהל הקבצים אל העמוד הזה. NoteCraft שואל מה לעשות איתו:

- **הוספת התמונה**: עותק נכנס לתיקיית `assets` של העמוד הזה והעמוד מציג אותו.
- **צירוף הקובץ**: אותו עותק, מוצג כקישור.
- **קישור לקובץ במקומו**: שום דבר לא מועתק, והקישור נשבר אם הקובץ זז.

**הוספה**, ואז **תמונה** או **קובץ** עושה אותו דבר ומבקש מכם לגרור את הקובץ.

## לאן זה הולך

```text
pictures-and-files/
  index.md
  assets/
    diagram.png
    budget.xlsx
```

התמונה נוסעת עם העמוד: הזיזו את התיקייה, והתמונה זזה איתה. השמות נעשים בטוחים לכל מערכת הפעלה,
שני קבצים לעולם לא חולקים שם, וקובץ מעל 512 MB נדחה.

## הדבקה

טבלה שהועתקה מאפליקציית הערות אחרת או מגיליון אלקטרוני מודבקת כטבלה. הדבקת תמונה מהלוח עדיין
לא נבנתה: שמרו אותה וגררו את הקובץ במקום זאת.

## תדפיסים

אפליקציות מסוימות יכולות להציג PDF או מסמך כתמונות על העמוד שלכם. NoteCraft עדיין לא יכול; PDF
שתצרפו נשמר כקובץ, והדו-שיח אומר זאת.

הבא: [שני תבניות עמוד](../page-formats/).
