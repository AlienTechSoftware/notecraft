תגית הופכת שורה למשהו: משימה לביצוע, דבר חשוב, שאלה שמחכה לתשובה. לחצו בשורה, ואז **בית**
ותיבת התגיות. בקשה של אותה תגית שוב מסירה אותה.

## לביצוע

- [ ] פתחו את המחברת הזאת
- [x] קראו את עמוד הפתיחה
- [ ] סמנו את התיבה שלמעלה בלחיצה עליה

שורת משימה היא פריט ברשימת משימות, שכל קורא Markdown מבין.

## התגיות האחרות

#important לצאת ביום שישי, לא בשבת.

#question האם הרכבת עוצרת בשדה התעופה?

#idea לשמור את הכרטיסים בעמוד, לא בדואר.

#remember מספר ההזמנה נמצא בקובץ המצורף.

NoteCraft מצייר את הסימן במקום המילה, אבל המילה היא מה שנמצא בקובץ, ולכן ההערות שלכם נשארות
קריאות בכל עורך וניתנות לחיפוש מהטרמינל. מילה שרק נראית כמו תגית, כמו #ideas בלי רווח אחריה,
נשארת כפי שהיא.

## מה עוד אין כאן

תגיות מותאמות אישית ועמוד סיכום שאוסף כל שורה מתויגת עדיין לא נבנו. הכפתור לחיפוש תגיות אומר
זאת.
