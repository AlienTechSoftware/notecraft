# Écrire une page

Cliquez dans une ligne et tapez. La page s'affiche telle qu'elle se lit : les titres en
caractères de titre, le **gras** et l'*italique* avec leur propre allure, le `code` dans une
boîte, le ~~barré~~ quand c'est réglé. Les marques qui les produisent restent dans le texte mais
s'effacent, pour que les mots passent devant.

## Blocs

Une page est une colonne de blocs. Ceci est un paragraphe. Les autres sortes sont en dessous.

> Une citation : les notes devraient survivre à l'application qui les a écrites.

| Touche | Ce qu'elle fait |
|---|---|
| Entrée | Une nouvelle ligne en dessous. Sur un élément de liste vide, termine la liste |
| Retour arrière en début de ligne | Rattache la ligne à celle du dessus |
| Tab, Maj+Tab | Plus ou moins de retrait sur un élément de liste |
| Haut, Bas | Aller à la ligne du dessus ou du dessous |
| Échap | Quitter la ligne |
| Ctrl+S | Enregistrer maintenant. La page s'enregistre de toute façon |

## Équations

Tapez du TeX entre deux signes dollar : $E = mc^2$ dans la ligne, ou un bloc à part :

$$
\int_0^1 x^2 \, dx = \tfrac{1}{3}
$$

NoteCraft dessine lui-même fractions, racines, sommes, intégrales, parenthèses et lettres
grecques. Ce qu'il ne connaît pas reste visible en texte au lieu de disparaître.

## Le ruban

**Accueil** contient les marques et les blocs, une galerie de styles et la galerie des
étiquettes. **Insertion** contient tableaux, images, fichiers, liens, équations, diagrammes et
la date du jour. **Affichage** contient la pleine page, la recherche, les lignes de réglure, le
zoom, le thème et la source de la page.

## La source de la page

Le fichier derrière cette page est à un clic : le bouton `< >` à côté de la page. Ce que vous
tapez dans l'un ou l'autre arrive dans le fichier. Servez-vous-en pour tout ce que l'éditeur ne
fait pas encore.
