# Bilder und Dateien

Ziehen Sie eine Datei aus Ihrem Dateimanager auf diese Seite. NoteCraft fragt, was damit
geschehen soll:

- **Bild einfügen**: Eine Kopie wandert in den Ordner `assets` dieser Seite, und die Seite zeigt sie.
- **Datei anhängen**: Dieselbe Kopie, als Link angezeigt.
- **Datei an ihrem Ort verlinken**: Nichts wird kopiert, und der Link bricht, wenn die Datei verschoben wird.

**Einfügen**, dann **Bild** oder **Datei**, tut dasselbe und bittet Sie, die Datei abzulegen.

## Wohin sie kommt

```text
pictures-and-files/
  index.md
  assets/
    diagram.png
    budget.xlsx
```

Das Bild reist mit der Seite: Verschieben Sie den Ordner, zieht das Bild mit. Namen werden für
jedes Betriebssystem sicher gemacht, zwei Dateien tragen nie denselben Namen, und eine Datei
über 512 MB wird abgelehnt.

## Einfügen aus der Zwischenablage

Eine Tabelle, die aus einer anderen Notiz-App oder einer Tabellenkalkulation kopiert wurde,
wird als Tabelle eingefügt. Ein Bild aus der Zwischenablage einzufügen ist noch nicht gebaut:
Speichern Sie es und ziehen Sie die Datei auf die Seite.

## Ausdrucke

Manche Anwendungen können ein PDF oder ein Dokument als Bilder auf die Seite legen. NoteCraft
kann das noch nicht; ein angehängtes PDF bleibt eine Datei, und der Dialog sagt das.
