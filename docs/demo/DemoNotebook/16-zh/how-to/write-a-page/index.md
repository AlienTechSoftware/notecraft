# 写一页

点击一行然后输入。页面按阅读时的样子显示：标题用标题字体，**粗体**和*斜体*各有自己的样子，`代码`在方框里，~~删除线~~表示已经完成。构成它们的标记留在文本里，但退到后面，让文字排在前面。

## 块

页面是一列块。这是一个段落。下面是其他种类。

> 一句引用：笔记应该比写下它的应用活得更久。

- 一个项目符号列表
- 第二项
  - 嵌套在下面的一项
1. 一个编号列表
2. 自动计数

| 按键 | 作用 |
|---|---|
| Enter | 在下方新起一行。在空的列表项上按下会结束列表 |
| 行首的 Backspace | 把这一行并入上一行 |
| Tab、Shift+Tab | 增加或减少列表项的缩进 |
| 上、下 | 移到上一行或下一行 |
| Escape | 离开这一行 |
| Ctrl+S | 立即保存。页面本来也会自动保存 |

## 公式

在美元符号之间输入 TeX：行内的 $E = mc^2$，或者单独一块：

$$
\int_0^1 x^2 \, dx = \tfrac{1}{3}
$$

NoteCraft 自己绘制分数、根号、求和、积分、括号和希腊字母。它不认识的内容会保留为文本，而不是消失。

## 功能区

**开始**包含标记和块、样式库和标签库。**插入**包含表格、图片、文件、链接、公式、图表和今天的日期。**视图**包含整页、搜索、横线、缩放、主题和页面源码。
