# 图片和文件

从文件管理器把文件拖到这一页上。NoteCraft 会问你要怎么处理：

- **插入图片**：一份拷贝进入这一页的 `assets` 文件夹，页面显示它。
- **附加文件**：同样的拷贝，显示为链接。
- **链接到文件所在位置**：不复制任何东西，文件移动后链接就会失效。

**插入**，然后**图片**或**文件**，做的是同一件事，并提示你把文件拖过来。

## 它放在哪里

```text
pictures-and-files/
  index.md
  assets/
    diagram.png
    budget.xlsx
```

图片随页面一起走：移动文件夹，图片也跟着移动。文件名会被处理成每个操作系统都安全的形式，两个文件永远不会同名，超过 512 MB 的文件会被拒绝。

## 粘贴

从另一个笔记应用或电子表格复制的表格，粘贴后仍是表格。从剪贴板粘贴图片还没有实现：先保存图片，再把文件拖进来。

## 打印输出

有些应用能把 PDF 或文档渲染成图片放到页面上。NoteCraft 还做不到；你附加的 PDF 会保留为文件，对话框会这样说明。
