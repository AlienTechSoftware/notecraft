两种页面格式

这一页是一个 HTML 文件。本分区的其他页面是 Markdown 文件。两种格式的编辑方式相同，在页面上分不出来；格式显示在右上角，保存状态旁边。

格式文件适合
HTML，内置默认index.html丰富的版式，以及来自别处的页面
CommonMark + GFMindex.md干净的差异和合并，以及单独阅读文件

在哪里做选择

  1. 创建页面时你选的格式。
  2. 上层分区、分区组或笔记本上设置的最近格式。
  3. 全局设置，顶栏里的默认格式框。
  4. 内置默认，HTML。

设置只改变新页面。已有的页面保留自己的格式，从文件名就能看出来，所以读一页从来不需要任何设置。

看看这一页的源码

点击页面旁边的 < > 按钮。文件头部用 <meta name="notecraft:..."> 标签保存页面的标识和日期；Markdown 页面把同样的信息放在前置元数据里。NoteCraft 只编辑 <body> 里面的内容。
