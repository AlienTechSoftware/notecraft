标签让一行变成某种东西：一件待办事项、一件重要的事、一个待回答的问题。点击一行，然后点**开始**和标签框。再次选择同一个标签会把它去掉。

## 待办

- [ ] 打开这个笔记本
- [x] 阅读欢迎页
- [ ] 点击上面的框把它勾上

待办行就是任务列表项，每个 Markdown 阅读器都认识。

## 其他标签

#important 周五出发，不是周六。

#question 火车在机场停吗？

#idea 把票放在页面里，别放在邮件里。

#remember 预订号在附件里。

NoteCraft 画出标记而不是单词，但文件里保存的是单词，所以你的笔记在任何编辑器里都能读，在终端里也能搜索。只是长得像标签的词，比如后面没有空格的 #ideas，会原样保留。

## 还没有的功能

自定义标签和汇总所有带标签行的摘要页还没有做。"查找标签"按钮会这样告诉你。
