按键作用
Enter在下方新起一行。在空的列表项上按下会结束列表
行首的 Backspace把这一行并入上一行
Tab、Shift+Tab增加或减少列表项的缩进
上、下移到上一行或下一行
Escape离开这一行
Ctrl+S立即保存。页面本来也会自动保存

公式

在美元符号之间输入 TeX：行内的 $E = mc^2$，或者单独一块：

\int_0^1 x^2 \, dx = \tfrac{1}{3}

NoteCraft 自己绘制分数、根号、求和、积分、括号和希腊字母。它不认识的内容会保留为文本，而不是消失。
