主题

右上角的太阳或月亮打开主题选择器：浅色和深色，各有七种强调色，一共 14 种。点一个色块就选中那种模式。色块下面的开关让 NoteCraft 重新跟随系统的浅色或深色设置。

每个主题的每种颜色都经过测试，和背景对比过，所以没有哪个主题会显示你读不清的文字。

笔记本和分区的颜色

右键点击笔记本、分区组或分区，然后选颜色。九种颜色，显示在图标和行的边缘。这个笔记本里的每个分组都有一种。

页面自己的视图

页面旁边的按钮作用
< >在代码视图中打开页面的所有文件
放大镜搜索所有页面
箭头整页：笔记本让开，直到你再按一次

视图还可以在页面后面加横线、缩放、隐藏页面标题。横线和缩放会被记住。

从上次离开的地方打开

NoteCraft 会重新打开你关闭时所在的页面，并展开它上面的分区。
