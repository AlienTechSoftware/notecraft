NoteCraft 没有自己的同步，也没有账户。笔记本是一个装着小文件的文件夹，所以把你的笔记本文件夹放在同步工具已经在看的地方：OneDrive、Dropbox、Google Drive、iCloud Drive、Syncthing、网络共享或 git 仓库。它们都不需要理解 NoteCraft。它们只是复制文件。

为什么行得通

  • 每页一个文件。 编辑一页只重写一个小文件，所以两台机器很少碰到同样的字节。
  • 原子写入。 页面先写到临时文件，再改名覆盖旧文件，所以同步客户端永远看不到写了一半的页面。
  • 短而安全的名字。 文件夹名最多 64 个字符，路径最多 255 个，Windows 拒绝的字符一概不写。
  • 会发现冲突副本。 当同步工具在页面旁边留下冲突副本时，检查器会报告：文件，然后检查，或者在终端运行 notecraft-cli check。

备份

备份就是文件夹的一份拷贝。没有别的东西需要导出。

页面历史

打开 History，再选 Page Versions，即可查看并恢复此页已保存的副本。要恢复已删除的 页面、分区或分区组，请打开 History，再选 Notebook Recycle Bin。这些功能在本设备上 运行，不能替代单独备份整个笔记本。

不处理的情况

NoteCraft 不会合并同一页的两个版本。如果同步工具生成了冲突副本，请自行决定保留哪个版本。
