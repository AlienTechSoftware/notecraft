笔记就是普通文件，放在普通文件夹里。

NoteCraft 保存笔记的方式和你保存文件一样：笔记本是一个文件夹，分区是一个文件夹，页面是一个文件夹，里面有一个文件和它的图片。没有任何东西锁在数据库里，所以你的同步工具已经在监视的任何文件夹都能变成同步的笔记本，备份就是一份拷贝。

在这里你可以做什么

本分区的每一页都在页面上展示 NoteCraft 的一个部分：

  • 写一页：标题、列表、粗体、链接、公式、快捷键。
  • 给一行加标签：待办框和其他标记。
  • 图片和文件：把文件拖到页面上。
  • 两种页面格式：HTML 或 Markdown，由你选择。
  • 同步与备份：把文件夹放在同步工具查看的地方。
  • 按你的喜好设置：14 种主题和九种颜色。
  • 从右到左：阿拉伯语、希伯来语、波斯语和乌尔都语。
  • 形状：绘图工具支持的全部十种形状。
  • 手写与绘图：可编辑的墨迹笔画。
  • Mermaid 图表：多种图表类型。
  • Vega 和 D3 图表：渲染图表与代码示例。
