수식

달러 기호 사이에 TeX를 쓰세요. 줄 안에서는 $E = mc^2$, 따로 한 블록으로는:

\int_0^1 x^2 \, dx = \tfrac{1}{3}

NoteCraft는 분수, 근호, 합, 적분, 괄호, 그리스 문자를 직접 그립니다. 모르는 것은 사라지지 않고 글자로 남습니다.
