노트는 평범한 파일, 평범한 폴더에.

NoteCraft는 여러분이 파일을 보관하듯 노트를 보관합니다. 노트북은 폴더이고, 섹션도 폴더이고, 페이지는 파일 하나와 그 그림들이 들어 있는 폴더입니다. 데이터베이스에 갇힌 것은 아무것도 없으므로, 동기화 도구가 이미 지켜보는 폴더라면 무엇이든 동기화된 노트북이 되고, 백업은 복사본 하나로 끝납니다.

여기서 할 수 있는 것

이 섹션의 각 페이지는 NoteCraft의 한 부분을 페이지 위에서 직접 보여 줍니다.

  • 페이지 쓰기: 제목, 목록, 굵게, 링크, 수식, 단축키.
  • 줄에 태그 달기: 할 일 상자와 다른 표시들.
  • 그림과 파일: 페이지에 파일을 끌어다 놓기.
  • 두 가지 페이지 형식: HTML 또는 Markdown, 원하는 대로.
  • 동기화와 백업: 동기화 도구가 보는 곳에 폴더 두기.
  • 내 취향대로: 14가지 테마와 아홉 가지 색.
  • 오른쪽에서 왼쪽으로: 아랍어, 히브리어, 페르시아어, 우르두어.
