태그는 줄에 뜻을 줍니다. 할 일, 중요한 것, 답을 기다리는 질문. 줄을 클릭한 뒤 홈의 태그 상자를 고르세요. 같은 태그를 다시 고르면 사라집니다.

할 일

  • ☐ 이 노트북 열기
  • ☑ 환영 페이지 읽기
  • ☐ 위의 상자를 클릭해서 체크하기

할 일 줄은 작업 목록 항목이고, 모든 Markdown 리더가 이해합니다.

다른 태그들

#important 토요일이 아니라 금요일에 출발.

#question 기차가 공항에 서나요?

#idea 표는 메일이 아니라 페이지에 두기.

#remember 예약 번호는 첨부 파일에 있음.

NoteCraft는 낱말 대신 표시를 그리지만, 파일에 있는 것은 낱말입니다. 그래서 노트는 어떤 편집기에서도 읽히고 터미널에서도 검색됩니다. 태그처럼 보이기만 하는 낱말, 예를 들어 뒤에 띄어쓰기가 없는 #ideas는 그대로 둡니다.

아직 없는 것

사용자 정의 태그와 태그 달린 줄을 모두 모으는 요약 페이지는 아직 만들어지지 않았습니다. "태그 찾기" 버튼이 그렇게 말해 줍니다.
