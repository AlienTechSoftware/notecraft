D3 kaynağı: bir çubuk grafik

Bu JavaScript bir D3 grafiğinin kaynak kodudur. NoteCraft kodu gösterir ama çalıştırmaz.

const data = [
  { month: "Oca", pages: 20 },
  { month: "Şub", pages: 38 },
  { month: "Mar", pages: 55 }
];

const svg = d3.select("svg")
  .attr("width", 400)
  .attr("height", 260);
const x = d3.scaleBand()
  .domain(data.map(d => d.month))
  .range([0, 360])
  .padding(0.15);
const y = d3.scaleLinear()
  .domain([0, d3.max(data, d => d.pages)])
  .range([220, 0]);

svg.selectAll("rect")
  .data(data)
  .join("rect")
  .attr("x", d => x(d.month))
  .attr("y", d => y(d.pages))
  .attr("width", x.bandwidth())
  .attr("height", d => 220 - y(d.pages));

D3 kaynağı: bir çizgi grafik

const data = [
  { month: "Oca", pages: 12 },
  { month: "Şub", pages: 29 },
  { month: "Mar", pages: 48 }
];

const svg = d3.select("svg")
  .attr("width", 400)
  .attr("height", 260);
const x = d3.scalePoint()
  .domain(data.map(d => d.month))
  .range([20, 360]);
const y = d3.scaleLinear()
  .domain([0, d3.max(data, d => d.pages)])
  .range([220, 0]);
const line = d3.line()
  .x(d => x(d.month))
  .y(d => y(d.pages));

svg.append("path")
  .datum(data)
  .attr("fill", "none")
  .attr("stroke", "currentColor")
  .attr("d", line);

Sayfada grafikleri görmek için çizilmiş Mermaid bloklarına bakın. Vega ve D3 örneklerini, NoteCraft bu biçimleri desteklemeye başlayana kadar kod olarak tutun.
