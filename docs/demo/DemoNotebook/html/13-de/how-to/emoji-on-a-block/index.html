Jeder Block hat oben links ein kleines +. Klicken Sie darauf, um das Emoji-Raster zu öffnen. Wählen Sie ein Emoji; es erscheint neben dem +. Um ein Emoji zu entfernen, klicken Sie es im Block an.

Ausprobieren

  1. Klicken Sie oben links auf dieses +.
  2. Scrollen Sie durch das Raster und wählen Sie ein Emoji. Es erscheint neben dem +.
  3. Klicken Sie im Block auf dieses Emoji. Es verschwindet.
