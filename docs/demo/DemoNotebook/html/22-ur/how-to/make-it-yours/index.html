تھیم

اوپر کا سورج یا چاند تھیم چننے والا کھولتا ہے: ہلکا اور گہرا، ہر ایک سات رنگوں میں، کل 14۔ ایک نمونہ وہی موڈ چنتا ہے۔ نمونوں کے نیچے کا سوئچ NoteCraft کو دوبارہ آپ کے سسٹم کی ہلکی یا گہری ترتیب پر چلاتا ہے۔

ہر تھیم کا ہر رنگ ایک ٹیسٹ سے اپنے پس منظر کے مقابل جانچا جاتا ہے، اس لیے کوئی تھیم آپ کو ایسا متن نہیں دکھا سکتا جو آپ پڑھ نہ سکیں۔

نوٹ بکوں اور سیکشنوں کے رنگ
