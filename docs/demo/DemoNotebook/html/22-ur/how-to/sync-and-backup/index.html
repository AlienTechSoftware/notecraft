NoteCraft کا اپنا کوئی سنک نہیں اور کوئی اکاؤنٹ نہیں۔ نوٹ بک چھوٹی فائلوں کا فولڈر ہے، اس لیے اپنا نوٹ بکس فولڈر وہاں رکھیں جہاں آپ کا سنک ٹول پہلے سے دیکھتا ہے: OneDrive، Dropbox، Google Drive، iCloud Drive، Syncthing، نیٹ ورک شیئر یا git ریپوزٹری۔ ان میں سے کسی کو NoteCraft سمجھنے کی ضرورت نہیں۔ وہ فائلیں نقل کرتے ہیں۔

یہ کیوں کام کرتا ہے

  • ہر صفحے کی ایک فائل۔ صفحہ ایڈٹ کرنے سے ایک چھوٹی فائل دوبارہ لکھی جاتی ہے، اس لیے دو مشینیں

شاذ ہی ایک جیسے بائٹس چھوتی ہیں۔

  • ایٹمی لکھائی۔ صفحہ عارضی فائل میں لکھا جاتا ہے اور پھر پرانی کی جگہ لے لیتا ہے، اس لیے سنک

کلائنٹ کبھی آدھا لکھا صفحہ نہیں دیکھتا۔

  • چھوٹے، محفوظ نام۔ فولڈر کے نام زیادہ سے زیادہ 64 حروف اور راستے 255، اور Windows جسے رد

کرتا ہے وہ کبھی نہیں لکھا جاتا۔

  • تنازع کی نقلیں نوٹ ہوتی ہیں۔ جب سنک ٹول صفحے کے ساتھ تنازع والی نقل چھوڑتا ہے تو چیکر

اطلاع دیتا ہے: فائل، پھر چیک، یا ٹرمینل سے notecraft-cli check۔

بیک اپ

بیک اپ فولڈر کی ایک نقل ہے۔ برآمد کرنے کو اور کچھ نہیں۔

صفحے کی تاریخ

اس صفحے کی محفوظ شدہ نقول دیکھنے اور بحال کرنے کے لیے History، پھر Page Versions کھولیں۔ حذف شدہ صفحات، سیکشنوں یا سیکشن گروپوں کو بحال کرنے کے لیے History، پھر Notebook Recycle Bin کھولیں۔ یہ سہولتیں اسی آلے پر کام کرتی ہیں اور نوٹ بک کے الگ بیک اپ کا بدل نہیں ہیں۔

جو نہیں سنبھالا جاتا

NoteCraft صفحے کے دو ورژن ضم نہیں کرتا۔ اگر سنک ٹول تنازع کی نقل بنائے تو خود فیصلہ کریں کہ کون سا ورژن رکھنا ہے۔
