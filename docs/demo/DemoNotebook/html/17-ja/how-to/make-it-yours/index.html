テーマ

右上の太陽または月でテーマ選択が開きます。ライトとダーク、それぞれ 7 つのアクセント色、合わせて 14 種類です。見本をクリックするとそのモードになります。見本の下のスイッチで、NoteCraft は再びシステムのライト／ダーク設定に従います。

どのテーマのどの色も背景との対比をテストで確かめているので、読めない文字を出すテーマはありません。

ノートブックとセクションの色

ノートブック、セクショングループ、セクションを右クリックして色を選びます。9 色がアイコンと行の端に表示されます。このノートブックのグループにはそれぞれ色が付いています。
