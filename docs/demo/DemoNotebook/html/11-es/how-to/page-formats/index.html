Dónde se decide

  1. El formato que eliges al crear la página.
  2. El formato más cercano fijado en una sección, grupo o cuaderno por encima.
  3. El ajuste global, la caja Formato predeterminado de la barra superior.
  4. El predeterminado incorporado, HTML.

Un ajuste cambia solo las páginas nuevas. Las que ya tienes conservan su formato, que se ve en el nombre del archivo, así que nunca hace falta un ajuste para leer una página.
