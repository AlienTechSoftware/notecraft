Une étiquette fait d'une ligne quelque chose : une tâche, un point important, une question à régler. Cliquez dans une ligne, puis sur Accueil et la case des étiquettes. Redemander la même étiquette la retire.

À faire

  • ☐ Ouvrir ce carnet
  • ☑ Lire la page de bienvenue
  • ☐ Cocher la case du dessus en cliquant dessus

Une ligne à faire est un élément de liste de tâches, que tout lecteur Markdown comprend.

Les autres étiquettes

#important Partir vendredi, pas samedi.

#question Le train s'arrête-t-il à l'aéroport ?

#idea Garder les billets dans la page, pas dans le courrier.

#remember La référence de réservation est dans le fichier joint.

NoteCraft dessine la marque à la place du mot, mais c'est le mot qui est dans le fichier, donc vos notes restent lisibles dans n'importe quel éditeur et cherchables depuis un terminal. Un mot qui ressemble seulement à une étiquette, comme #ideas sans espace derrière, est laissé tel quel.

Ce qui manque encore

Les étiquettes personnalisées et une page de synthèse qui rassemble toutes les lignes étiquetées ne sont pas faites. Le bouton Rechercher les étiquettes le dit.
