Many note taking apps keep a whole notebook in one binary file, and a text editor shows noise. A NoteCraft page is a folder of plain files, and the code view shows you that folder, file by file. Try it now: press the < > button beside this page.

What you will see

On the left, Files in this page: the page's own file, index.md, first, then anything else in the folder. A file that nothing on the page uses is marked not used by the page. On the right is the file you picked. This is the page you are reading, so the viewer shows its own text.

The page file is shown whole: its head (the page's id, title, order, dates and settings) and under it the body. You can edit all of it. Press the same button again to close the view, and the page is drawn again from what you wrote.

FileWhat the viewer showsCan you type in it?

A file over 256 KB shows its first part and says so.

What it shows you

  • A page arranged in boxes has a div with class="nc-box" around each box.
  • A drawing is a file, ink.svg, and the page's text names it with one line.
  • Tags and links are plain text.

Nothing is hidden: if the page shows it, a file in this folder holds it.
