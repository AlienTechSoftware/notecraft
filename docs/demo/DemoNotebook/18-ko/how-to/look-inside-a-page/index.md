# 페이지 안을 들여다보기

많은 노트 앱은 노트북 전체를 바이너리 파일 하나에 담아 두기 때문에, 텍스트 편집기로 열면 알아볼 수 없는 문자만 보입니다. NoteCraft의 페이지는 평범한 파일이 담긴 폴더이고, 코드 보기는 그 폴더를 파일 하나씩 보여 줍니다. 지금 해 보세요. 이 페이지 옆의 `< >` 버튼을 누르세요.

## 보이는 것

왼쪽에는 **이 페이지의 파일**이 있습니다. 먼저 페이지 자체의 파일 `index.md`, 그다음 폴더 안의 나머지 것들입니다. 페이지에서 아무것도 쓰지 않는 파일에는 *페이지에서 쓰지 않음*이라고 표시됩니다. 오른쪽에는 고른 파일이 있습니다. 지금 읽고 있는 것이 이 페이지이므로, 뷰어에는 이 페이지 자신의 텍스트가 나옵니다.

페이지 파일은 **머리글**을 회색으로 보여 줍니다. 페이지의 ID, 제목, 순서, 날짜입니다. 여기에는 입력할 수 없으므로 손으로 고쳐도 페이지의 ID가 망가지지 않습니다. 그 아래가 **본문**이고, 본문은 고칠 수 있습니다. 같은 버튼을 다시 누르면 보기가 닫히고, 본문에 있는 내용으로 페이지가 다시 그려집니다.

| 파일 | 뷰어가 보여 주는 것 | 입력할 수 있나요? |
|---|---|---|
| 페이지 파일 `index.md` 또는 `index.html` | 머리글과, 저장된 그대로의 본문 | 본문 |
| 그림 `ink.svg` | SVG 텍스트와 펜의 자체 측정값 | 예, 조심해서 |
| 사진 | 사진 | 아니요 |
| 그 밖의 텍스트 | 그 텍스트 | 아니요 |
| 그 밖의 모든 것 | 이름, 크기, 종류 | 아니요 |

256 KB가 넘는 파일은 앞부분만 보여 주고 그렇다고 알려 줍니다.

## 알 수 있는 것

- 상자로 배치한 페이지에는 각 상자를 둘러싼 `class="nc-box"`가 있는 `div`가 있습니다.
- 그림은 `ink.svg`라는 파일이고, 페이지의 텍스트가 한 줄로 그 이름을 적어 둡니다.
- 태그와 링크는 평범한 텍스트입니다.

숨겨진 것은 없습니다. 페이지가 보여 주는 것은 이 폴더의 어떤 파일에 들어 있습니다.
