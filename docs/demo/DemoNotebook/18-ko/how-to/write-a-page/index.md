줄을 클릭하고 입력하세요. 페이지는 읽을 때의 모습으로 보입니다. 제목은 제목 글꼴로, **굵게**와 *기울임*은 각자의 모양으로, `코드`는 상자 안에, ~~취소선~~은 끝난 것에. 이를 만드는 기호는 글에 남지만 뒤로 물러나 낱말이 먼저 보입니다.

## 블록

페이지는 블록이 세로로 쌓인 것입니다. 이것은 문단입니다. 아래는 다른 종류들입니다.

> 인용: 노트는 그것을 쓴 앱보다 오래 살아남아야 한다.

- 글머리 기호 목록
- 두 번째 항목
  - 그 아래에 중첩된 항목
1. 번호 목록
2. 번호는 저절로 매겨집니다

| 키 | 동작 |
|---|---|
| Enter | 아래에 새 줄. 빈 목록 항목에서는 목록을 끝냄 |
| 줄 처음에서 Backspace | 윗줄과 합침 |
| Tab, Shift+Tab | 목록 항목 들여쓰기를 늘리거나 줄임 |
| 위, 아래 | 윗줄이나 아랫줄로 이동 |
| Escape | 줄에서 나가기 |
| Ctrl+S | 지금 저장. 페이지는 어차피 스스로 저장됨 |

## 수식

달러 기호 사이에 TeX를 쓰세요. 줄 안에서는 $E = mc^2$, 따로 한 블록으로는:

$$
\int_0^1 x^2 \, dx = \tfrac{1}{3}
$$

NoteCraft는 분수, 근호, 합, 적분, 괄호, 그리스 문자를 직접 그립니다. 모르는 것은 사라지지 않고 글자로 남습니다.

## 리본

**홈**에는 기호와 블록, 스타일 갤러리, 태그 갤러리가 있습니다. **삽입**에는 표, 그림, 파일, 링크, 수식, 다이어그램, 오늘 날짜가 있습니다. **보기**에는 전체 페이지, 검색, 줄선, 확대, 테마, 페이지 원본이 있습니다.

## 페이지 원본
