Deux formats de page

Cette page est un fichier HTML. Les autres pages de cette section sont des fichiers Markdown. Les deux se modifient de la même façon et ne se distinguent pas sur la page ; le format est indiqué en haut à droite, à côté de l'état d'enregistrement.

Où le choix se fait

  1. Le format choisi à la création de la page.
  2. Le format le plus proche fixé sur une section, un groupe ou un carnet au-dessus.
  3. Le réglage global, la case Format par défaut de la barre du haut.
  4. Le réglage par défaut intégré, HTML.

Un réglage ne change que les nouvelles pages. Celles que vous avez gardent leur format, visible dans le nom du fichier, donc aucun réglage n'est jamais nécessaire pour lire une page.

Regardez la source de cette page

Cliquez sur le bouton < > à côté de la page. L'en-tête du fichier porte l'identité et les dates de la page sous forme de balises <meta name="notecraft:..."> ; une page Markdown porte la même chose dans son en-tête. NoteCraft ne modifie que ce qui est dans <body>.
