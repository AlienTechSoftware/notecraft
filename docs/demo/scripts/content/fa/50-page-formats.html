دو قالب صفحه

این صفحه یک پرونده HTML است. صفحه‌های دیگر این بخش پرونده‌های Markdown هستند. هر دو به یک شکل ویرایش می‌شوند و روی صفحه از هم بازشناخته نمی‌شوند؛ قالب در بالای صفحه کنار وضعیت ذخیره نشان داده می‌شود.

قالبپروندهمناسب برای
HTML، پیش‌فرض داخلیindex.htmlچیدمان غنی، و صفحه‌هایی که از جای دیگر آمده‌اند
CommonMark + GFMindex.mdتفاوت‌ها و ادغام‌های تمیز، و خواندن پرونده به تنهایی

انتخاب کجا انجام می‌شود

  1. قالبی که هنگام ساختن صفحه انتخاب می‌کنید.
  2. نزدیک‌ترین قالب تنظیم‌شده روی بخش، گروه یا دفتر بالای آن.
  3. تنظیم سراسری، جعبه قالب پیش‌فرض در نوار بالا.
  4. پیش‌فرض داخلی، HTML.

یک تنظیم فقط صفحه‌های تازه را عوض می‌کند. صفحه‌هایی که دارید قالب خود را نگه می‌دارند، که از نام پرونده پیداست، پس برای خواندن یک صفحه هیچ تنظیمی لازم نیست.

به منبع این صفحه نگاه کنید

دکمه < > کنار صفحه را بزنید. سر پرونده هویت و تاریخ‌های صفحه را به شکل برچسب‌های <meta name="notecraft:..."> دارد؛ صفحه Markdown همین را در پیش‌درآمد خود دارد. NoteCraft فقط درون <body> را ویرایش می‌کند.

بعدی: همگام‌سازی و پشتیبان.

این صفحه را یک مدل هوش مصنوعی ترجمه کرده است. از اصلاح‌ها استقبال می‌شود.
