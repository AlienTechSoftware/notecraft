# Eine Seite schreiben

Klicken Sie in eine Zeile und tippen Sie. Die Seite wird so angezeigt, wie sie gelesen wird:
Überschriften in Überschriftenschrift, **fett** und *kursiv* mit ihrem eigenen Aussehen,
`Code` in einem Kasten, ~~durchgestrichen~~, wenn es erledigt ist. Die Zeichen, die das
bewirken, bleiben im Text, treten aber zurück, damit die Wörter vorne stehen.

## Blöcke

Eine Seite ist eine Spalte aus Blöcken. Dies ist ein Absatz. Darunter die anderen Arten.

> Ein Zitat: Notizen sollten die Anwendung überleben, die sie geschrieben hat.

- Eine Aufzählung
- mit einem zweiten Punkt
  - und einem darunter eingerückten
1. Eine nummerierte Liste
2. die von selbst zählt

| Taste | Was sie tut |
|---|---|
| Eingabe | Eine neue Zeile darunter. Auf einem leeren Listenpunkt beendet sie die Liste |
| Rücktaste am Zeilenanfang | Hängt die Zeile an die darüber an |
| Tab, Umschalt+Tab | Mehr oder weniger Einzug bei einem Listenpunkt |
| Hoch, Runter | Zur Zeile darüber oder darunter |
| Esc | Die Zeile verlassen |
| Strg+S | Jetzt speichern. Die Seite speichert sich ohnehin selbst |

## Formeln

Tippen Sie TeX zwischen Dollarzeichen: $E = mc^2$ in der Zeile oder als eigener Block:

$$
\int_0^1 x^2 \, dx = \tfrac{1}{3}
$$

NoteCraft zeichnet Brüche, Wurzeln, Summen, Integrale, Klammern und griechische Buchstaben
selbst. Was es nicht kennt, bleibt als Text sichtbar, statt zu verschwinden.

## Das Menüband

**Start** enthält die Zeichen und Blöcke, eine Formatvorlagen-Galerie und die
Markierungs-Galerie. **Einfügen** enthält Tabellen, Bilder, Dateien, Links, Formeln, Diagramme
und das heutige Datum. **Ansicht** enthält Ganzseitenansicht, Suche, Linien, Zoom, das Design
und den Seitenquelltext.

## Der Seitenquelltext

Die Datei hinter dieser Seite ist einen Klick entfernt: die Schaltfläche `< >` neben der Seite.
Was Sie in einer der beiden tippen, landet in der Datei. Nutzen Sie ihn für alles, was der
Editor noch nicht kann.
