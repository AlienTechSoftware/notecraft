# Eine Seite über einen Link öffnen

## Geplant: Links, die NoteCraft öffnen

NoteCraft soll künftig eine bestimmte Notizbuchseite über einen Link aus einem Browser, einer E-Mail, einem Chat oder einer anderen Anwendung öffnen können. Das Betriebssystem soll den Linktyp `notecraft:` verwenden, um NoteCraft zu starten und die gewünschte Seite zu öffnen. Je nach Betriebssystem und Browser musst du möglicherweise bestätigen, dass die Anwendung geöffnet werden darf.

Diese Funktion ist **noch nicht verfügbar**. NoteCraft registriert `notecraft:` derzeit nicht beim Betriebssystem und öffnet die angegebene Seite nicht, wenn ein externer Link aufgerufen wird. Einen NoteCraft-Seitenlink zu kopieren bedeutet also nicht, dass er sich heute in einem Browser öffnen lässt.

## Geplante Registrierung

- **Windows-Installer:** NoteCraft während der Installation registrieren und die Registrierung bei der Deinstallation entfernen.
- **Portables Windows-ZIP:** Eine separate Aktion **NoteCraft-Links registrieren** anbieten, die du bewusst ausführst, sowie eine passende Möglichkeit zum Aufheben der Registrierung. Das Entpacken des ZIP-Archivs allein registriert den Link nicht.
- **macOS:** Den Linktyp im NoteCraft-App-Bundle deklarieren.
- **Linux:** Eine Desktop-Anwendungszuordnung für den Linktyp installieren.

Die Registrierung teilt dem Betriebssystem nur mit, welche Anwendung einen Link entgegennehmen kann. NoteCraft muss außerdem das passende Notizbuch und die Seite finden, den Link an eine bereits laufende Anwendung weitergeben und verständlich erklären, wenn das Notizbuch oder die Seite fehlt. Auch das gehört zur geplanten Funktion.
