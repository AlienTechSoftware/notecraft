# 그림과 파일

파일 관리자에서 파일을 이 페이지로 끌어다 놓으세요. NoteCraft가 어떻게 할지 묻습니다.

- **그림 삽입**: 복사본이 이 페이지의 `assets` 폴더에 들어가고 페이지에 보입니다.
- **파일 첨부**: 같은 복사본을 링크로 보여 줍니다.
- **있는 곳의 파일에 링크**: 아무것도 복사하지 않습니다. 파일이 옮겨지면 링크가 끊어집니다.

**삽입**에서 **그림**이나 **파일**을 골라도 같은 일을 하며, 파일을 끌어다 놓으라고 안내합니다.

## 어디로 가나

```text
pictures-and-files/
  index.md
  assets/
    diagram.png
    budget.xlsx
```

그림은 페이지와 함께 움직입니다. 폴더를 옮기면 그림도 따라갑니다. 이름은 모든 운영 체제에서 안전하게 바뀌고, 두 파일이 같은 이름을 갖는 일은 없으며, 512 MB가 넘는 파일은 거부됩니다.

## 붙여넣기

다른 노트 앱이나 스프레드시트에서 복사한 표는 표로 붙여집니다. 그림을 붙여넣으려면 페이지를 클릭하고 **Ctrl+V**를 누르세요. NoteCraft가 페이지의 `assets` 폴더에 복사본을 저장한 뒤 노트에 삽입합니다.

## 인쇄물

어떤 앱은 PDF나 문서를 그림으로 바꿔 페이지에 넣습니다. NoteCraft는 아직 그렇게 못 합니다. 첨부한 PDF는 파일로 남고, 대화 상자가 그렇게 알려 줍니다.
