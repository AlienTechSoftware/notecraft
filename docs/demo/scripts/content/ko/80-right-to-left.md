# 오른쪽에서 왼쪽으로

아랍어, 히브리어, 페르시아어, 우르두어는 오른쪽에서 읽습니다. NoteCraft도 그렇게 그립니다. 글자는 이어지고, 줄은 오른쪽 가장자리에서 시작하며, 두 방향이 섞인 줄은 유니코드 알고리즘으로 배열되므로 가격의 숫자는 올바른 방향을 지킵니다.

السعر 123 ريال

이를 가능하게 하는 글꼴은 앱에 들어 있으므로, 위의 줄은 아랍 문자 글꼴이 없는 기기에서도 똑같이 보입니다. 히브리 문자와 힌디어 글꼴도 들어 있습니다.

שלום עולם

नमस्ते दुनिया

## 세 가지 방향, 세 가지 조절

| 조절 | 위치 | 정하는 것 |
|---|---|---|
| **페이지** | **홈**의 **방향** | 페이지 전체를 읽는 방향. 자기 글자가 없는 줄은 이것을 따름 |
| **문단** | **기본 텍스트**의 정렬 메뉴 | 커서가 있는 문단을 읽는 방향 |
| **구간** | 방향 그룹의 **더 보기...** | 선택한 글, 또는 다음에 입력할 글을 읽는 방향 |

페이지 방향은 NoteCraft만의 것입니다. 사람들이 쓰던 앱에는 이런 설정이 없지만, 아랍어로 쓴 노트북에는 필요합니다.

## 설정은 어디에 보관되나

글 자체에. 페이지 방향은 Markdown 페이지의 프런트 매터에 있는 `dir: rtl`, 또는 HTML 페이지의 meta 태그입니다. 문단 방향은 문단 첫머리의 보이지 않는 문자 하나, 유니코드의 오른쪽에서 왼쪽 또는 왼쪽에서 오른쪽 표시입니다. 둘 다 다른 어떤 편집기에서도 살아남습니다.

이 노트북의 아랍어, 페르시아어, 우르두어, 히브리어 그룹은 처음부터 끝까지 오른쪽에서 왼쪽으로 쓰여 있습니다. [시작 페이지](../../../00-start/welcome/)에서 하나 열어 비교해 보세요.
