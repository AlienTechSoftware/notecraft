# 메뉴와 이동

마우스 오른쪽 버튼을 누르면 다음에 할 수 있는 일이 나타나며, 선택지는 클릭한 위치에 따라 달라집니다. 키보드 단축키를 쓰면 마우스 없이도 페이지 사이를 이동할 수 있습니다.

![탐색기의 페이지 메뉴, 읽기 전용으로 잠그기 항목 표시](assets/page-menu.png)

| 마우스 오른쪽 버튼을 누르는 곳 | 메뉴가 제공하는 것 |
|---|---|
| 탐색기의 페이지 | 새 페이지, 하위 페이지 추가, 읽기 전용으로 잠그기 또는 잠금 해제, 이름 바꾸기, 이동 또는 복사, 페이지 링크 복사, 폴더 열기, 페이지 버전, 삭제 |
| 페이지 본문 | 붙여넣기, 잘라내기, 복사, 삽입 항목(표, 링크, 수식, 날짜와 시간, 사진, 파일), 그리고 읽기 전용으로 잠그기 또는 잠금 해제. 잠긴 페이지는 복사와 잠금 해제만 보여 줍니다 |
| 페이지 목록의 빈 공간 | 새 페이지, 그리고 열린 페이지의 잠그기 또는 잠금 해제 |
| 탐색기의 빈 공간 | 새 노트북, 폴더 열기, 노트북 폴더 보기, 그리고 열린 페이지의 잠그기 또는 잠금 해제 |

## 페이지 잠그기

읽기 전용으로 잠그기는 잠금 정보를 페이지 안에 저장하므로, 페이지 폴더를 복사하거나 동기화해도 잠금이 함께 갑니다. 잠긴 페이지는 제목과 내용을 그대로 유지합니다. 제목 칸에는 입력할 수 없고 편집은 거부됩니다. 다시 편집하려면 같은 메뉴에서 잠금 해제를 고르세요.

## 이동

- Ctrl+Page Up과 Ctrl+Page Down: 페이지 목록에서 위 또는 아래 페이지로 이동합니다.
- Alt+왼쪽과 Alt+오른쪽, 또는 마우스의 뒤로와 앞으로 버튼: 연 페이지들 사이를 뒤로 또는 앞으로 이동합니다.
- 모든 페이지 검색: 오른쪽 위의 상자에서 모든 페이지의 단어를 찾습니다. Enter를 누르면 선택한 결과가 열립니다.
