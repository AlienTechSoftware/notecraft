# ようこそ

![ノートに書きこむ NoteCraft のコアラ](assets/banner-ja.png)

*ノートはただのファイル、ただのフォルダーに。*

NoteCraft はノートを、あなたがファイルを保存するのと同じやり方で保存します。ノートブックはフォルダー、セクションはフォルダー、ページはひとつのファイルとその画像が入ったフォルダーです。データベースに閉じ込められるものは何もないので、同期ツールがすでに見ているフォルダーはそのまま同期されたノートブックになり、バックアップはコピーひとつで済みます。

## ここでできること

このセクションの各ページは、NoteCraft の機能をページそのものの上で見せます。

- [ページを書く](../write-a-page/)：見出し、リスト、太字、リンク、数式、キー操作。
- [行にタグを付ける](../tag-a-line/)：ToDo のチェックボックスとその他のマーク。
- [画像とファイル](../pictures-and-files/)：ページにファイルをドロップする。
- [ふたつのページ形式](../page-formats/)：HTML か Markdown か、好きな方を。
- [同期とバックアップ](../sync-and-backup/)：フォルダーを同期ツールが見る場所に置く。
- [自分好みにする](../make-it-yours/)：14 のテーマと 9 つの色。
- [右から左へ](../right-to-left/)：アラビア語、ヘブライ語、ペルシア語、ウルドゥー語。
- [図形](../shapes/)：描画できる 10 種類の図形。
- [手書きと描画](../handwriting-and-drawing/)：編集できるインクの線。
- [Mermaid 図](../mermaid-diagrams/)：複数の図の種類。
- [Vega と D3 のチャート](../charts-vega-d3/)：表示されるチャートとコード例。

## さっそく試す

この段落のどこかをクリックして入力してください。入力をやめて約 1 秒でページは自動的に保存されます。行末で **Enter** を押すと新しい段落、**Escape** でその行から抜けます。
