# 画像とファイル

ファイルマネージャーからこのページにファイルをドラッグします。NoteCraft がどうするか尋ねます。

- **画像を挿入**：コピーがこのページの `assets` フォルダーに入り、ページに表示されます。
- **ファイルを添付**：同じコピーをリンクとして表示します。
- **元の場所のファイルにリンク**：何もコピーしません。ファイルが移動するとリンクは切れます。

**挿入**から**画像**または**ファイル**を選んでも同じで、ファイルをドロップするよう促されます。

## どこに入るか

```text
pictures-and-files/
  index.md
  assets/
    diagram.png
    budget.xlsx
```

画像はページと一緒に移動します。フォルダーを動かせば画像も付いてきます。名前はどの OS でも安全な形にされ、同じ名前のファイルは二つできず、512 MB を超えるファイルは受け付けません。

## 貼り付け

ほかのノートアプリや表計算からコピーした表は、表として貼り付きます。画像を貼り付けるには、ページをクリックして **Ctrl+V** を押します。NoteCraft は画像のコピーをページの `assets` フォルダーに保存し、ノートに挿入します。

## プリントアウト

PDF や文書を画像としてページに展開できるアプリもあります。NoteCraft はまだできません。添付した PDF はファイルのまま保たれ、ダイアログがそう伝えます。
