# 右から左へ

アラビア語、ヘブライ語、ペルシア語、ウルドゥー語は右から読みます。NoteCraft もそのように描きます。文字はつながり、行は右端からぶら下がり、両方向が混じる行は Unicode のアルゴリズムで並べられるので、価格の数字は正しい向きを保ちます。

السعر 123 ريال

これを可能にするフォントはアプリに同梱されているので、上の行はアラビア文字のフォントがない機械でも同じに見えます。ヘブライ文字とヒンディー語にも同梱のフォントがあります。

שלום עולם

नमस्ते दुनिया

## 三つの方向、三つのコントロール

| コントロール | 場所 | 設定するもの |
|---|---|---|
| **ページ** | **ホーム**の**方向** | ページ全体を読む向き。自分の文字を持たない行はこれに従う |
| **段落** | **基本テキスト**の配置メニュー | カーソルのある段落を読む向き |
| **範囲** | 方向グループの**その他...** | 選択範囲、または次に入力する文字を読む向き |

ページの方向は NoteCraft 独自のものです。人々が使ってきたアプリにこの設定はありませんが、アラビア語で書かれたノートブックには必要です。

## 設定はどこに保存されるか

本文そのものに。ページの方向は Markdown ページのフロントマターの `dir: rtl`、または HTML ページの meta タグです。段落の方向は段落の先頭の見えない 1 文字、Unicode の右から左、または左から右のマークです。どちらもほかのエディターで開いても保たれます。

このノートブックのアラビア語、ペルシア語、ウルドゥー語、ヘブライ語のグループは全体が右から左に書かれています。[最初のページ](../../../00-start/welcome/)から開いて比べてみてください。
