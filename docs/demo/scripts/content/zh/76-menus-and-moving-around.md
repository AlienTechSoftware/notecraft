# 菜单与页面切换

右键菜单会列出您接下来可以做的事，选项取决于您点击的位置。键盘快捷键让您不用鼠标也能切换页面。

![导航器中页面的菜单，其中有「锁定为只读」](assets/page-menu.png)

| 右键点击的位置 | 菜单提供的内容 |
|---|---|
| 导航器中的页面 | 新建页面、添加子页面、锁定为只读或解锁、重命名、移动或复制、复制页面链接、打开文件夹、页面版本、删除 |
| 页面正文 | 粘贴、剪切和复制，插入项（表格、链接、公式、日期和时间、图片、文件），以及锁定为只读或解锁。已锁定的页面只提供复制和解锁 |
| 页面列表的空白处 | 新建页面，以及对当前打开页面的锁定或解锁 |
| 导航器的空白处 | 新建笔记本、打开文件夹、显示笔记本文件夹，以及对当前打开页面的锁定或解锁 |

## 锁定页面

「锁定为只读」把锁定信息保存在页面本身中，因此复制或同步页面文件夹时，锁定会随页面一起移动。已锁定的页面保留标题和正文：标题框无法输入，编辑会被拒绝。在同一菜单中选择「解锁」即可重新编辑。

## 切换页面

- Ctrl+Page Up 和 Ctrl+Page Down：切换到页面列表中的上一个或下一个页面。
- Alt+左 和 Alt+右，或鼠标的后退和前进按钮：在您打开过的页面之间后退和前进。
- 搜索所有页面：右上角的搜索框可以在所有页面中查找文字。按 Enter 打开所选结果。
