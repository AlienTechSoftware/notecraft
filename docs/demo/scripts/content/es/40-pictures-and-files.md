# Imágenes y archivos

Arrastra un archivo desde tu explorador de archivos hasta esta página. NoteCraft te pregunta qué
hacer con él:

- **Insertar la imagen**: una copia va a la carpeta `assets` de esta página y la página la muestra.
- **Adjuntar el archivo**: la misma copia, mostrada como enlace.
- **Enlazar al archivo donde está**: no se copia nada, y el enlace se rompe si el archivo se mueve.

**Insertar**, luego **Imagen** o **Archivo**, hace lo mismo y te pide que sueltes el archivo.

## Dónde va

```text
pictures-and-files/
  index.md
  assets/
    diagram.png
    budget.xlsx
```

La imagen viaja con la página: mueve la carpeta y la imagen se mueve con ella. Los nombres se
hacen seguros para cualquier sistema operativo, dos archivos nunca comparten nombre, y un archivo
de más de 512 MB se rechaza.

## Pegar

Una tabla copiada de otra aplicación de notas o de una hoja de cálculo se pega como tabla. Pegar
una imagen desde el portapapeles todavía no está hecho: guárdala y suelta el archivo.

## Impresiones

Algunas aplicaciones pueden convertir un PDF o un documento en imágenes sobre la página.
NoteCraft todavía no puede; un PDF que adjuntes se queda como archivo, y el diálogo lo dice.

Siguiente: [Dos formatos de página](../page-formats/).
