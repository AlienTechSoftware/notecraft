שני תבניות עמוד

העמוד הזה הוא קובץ HTML. העמודים האחרים במקטע הזה הם קובצי Markdown. שניהם נערכים באותה דרך, ואי אפשר להבדיל ביניהם על העמוד; התבנית מוצגת למעלה, ליד מצב השמירה.

תבניתקובץטובה ל
HTML, ברירת המחדל המובניתindex.htmlפריסה עשירה, ועמודים שהגיעו ממקום אחר
CommonMark + GFMindex.mdהבדלים ומיזוגים נקיים, וקריאת הקובץ בפני עצמו

היכן נעשית הבחירה

  1. התבנית שבוחרים כשיוצרים את העמוד.
  2. התבנית הקרובה ביותר שהוגדרה על מקטע, קבוצה או מחברת מעליו.
  3. ההגדרה הכללית, התיבה תבנית ברירת מחדל בסרגל העליון.
  4. ברירת המחדל המובנית, HTML.

הגדרה משנה עמודים חדשים בלבד. העמודים שכבר יש לכם שומרים על התבנית שלהם, שנראית משם הקובץ, ולכן לעולם לא נדרשת הגדרה כדי לקרוא עמוד.

הביטו במקור של העמוד הזה

לחצו על הכפתור < > ליד העמוד. ראש הקובץ נושא את זהות העמוד ותאריכיו כתגיות <meta name="notecraft:...">; עמוד Markdown נושא אותו דבר בכותרת הקדמית שלו. NoteCraft עורך רק את מה שבתוך <body>.

הבא: סנכרון וגיבוי.

העמוד הזה תורגם על ידי מודל בינה מלאכותית. תיקונים יתקבלו בברכה.
