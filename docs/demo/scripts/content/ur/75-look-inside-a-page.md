# صفحے کے اندر جھانکیں

نوٹ لینے والی بہت سی ایپس پوری نوٹ بک ایک ہی بائنری فائل میں رکھتی ہیں، اور ٹیکسٹ ایڈیٹر اس میں صرف بے معنی نشان دکھاتا ہے۔ NoteCraft کا صفحہ سادہ فائلوں کا ایک فولڈر ہے، اور کوڈ ویو آپ کو وہی فولڈر فائل بہ فائل دکھاتا ہے۔ ابھی آزمائیں: اس صفحے کے ساتھ والا `< >` بٹن دبائیں۔

## آپ کو کیا نظر آئے گا

بائیں طرف **اس صفحے کی فائلیں** ہیں: سب سے پہلے صفحے کی اپنی فائل، `index.md`، پھر فولڈر میں باقی جو کچھ ہے۔ جس فائل کو صفحے پر کوئی چیز استعمال نہیں کرتی اس پر *صفحے میں استعمال نہیں ہوئی* لکھا ہوتا ہے۔ دائیں طرف وہ فائل ہے جو آپ نے چنی۔ یہ وہی صفحہ ہے جو آپ پڑھ رہے ہیں، اس لیے ناظر اس کا اپنا متن دکھاتا ہے۔

صفحے کی فائل اپنا **ہیڈ** سرمئی رنگ میں دکھاتی ہے: صفحے کی شناخت، عنوان، ترتیب اور تاریخیں۔ اس میں آپ ٹائپ نہیں کر سکتے، اس لیے ہاتھ سے کی گئی تبدیلی صفحے کی شناخت خراب نہیں کر سکتی۔ اس کے نیچے **بدن** ہے، جسے آپ بدل سکتے ہیں۔ ویو بند کرنے کے لیے وہی بٹن دوبارہ دبائیں، اور صفحہ بدن میں جو کچھ ہے اسی سے دوبارہ بنایا جاتا ہے۔

| فائل | ناظر کیا دکھاتا ہے | کیا اس میں ٹائپ کر سکتے ہیں؟ |
|---|---|---|
| صفحے کی فائل، `index.md` یا `index.html` | ہیڈ، اور بدن جیسا محفوظ ہوا تھا | بدن میں |
| ایک ڈرائنگ، `ink.svg` | SVG متن، قلم کی اپنی ریڈنگز کے ساتھ | ہاں، احتیاط سے |
| ایک تصویر | تصویر | نہیں |
| دوسرا متن | اس کا متن | نہیں |
| باقی سب کچھ | اس کا نام، سائز اور قسم | نہیں |

256 KB سے بڑی فائل اپنا پہلا حصہ دکھاتی ہے اور یہ بتاتی بھی ہے۔

## یہ آپ کو کیا دکھاتا ہے

- خانوں میں سجے صفحے میں ہر خانے کے گرد `class="nc-box"` والا ایک `div` ہوتا ہے۔
- ڈرائنگ ایک فائل ہے، `ink.svg`، اور صفحے کا متن اسے ایک سطر میں بتاتا ہے۔
- ٹیگ اور لنک سادہ متن ہیں۔

کچھ بھی چھپا ہوا نہیں: صفحہ جو دکھاتا ہے، اسے اس فولڈر کی کوئی فائل رکھتی ہے۔
