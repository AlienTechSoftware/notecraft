## Which logo to use

- App icon and installer art: `notecraft-512.png`, scaled down as needed.
- README and web pages: the Try NoteCraft! badge for links to the demo,
  the social card for link previews (dark or light to match the page).
- The koala is NoteCraft's mark. Do not substitute Demelien, the AlienTech
  mascot, for it.
