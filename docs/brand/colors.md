# Colour palette

## Brand purples

| Colour | Hex | Used for |
|---|---|---|
| NoteCraft purple | `#884ACB` | NoteCraft logo, Try NoteCraft! badge, Discord `nc_admin` role |
| AlienTech purple | `#643CEA` | AlienTech badge, alientech.software, Discord `nc_super_admin` role |
| Light purple | `#B794E6` | Discord `nc_dev` role |

NoteCraft purple was sampled from the NoteCraft logo. The Discord role
colours shade down by tier: super-admin darkest, admin brand purple, dev
lightest. The `nc_user` role has no colour.

## Website (notecraft.cloud)

The site's palette lives in `website/styles.css`. Its accents differ
slightly from the logo purple; they were chosen for contrast on dark and
light backgrounds.

| Token | Dark theme | Light theme |
|---|---|---|
| Accent / link | `#b085e8` | `#7a45b8` |
| Band | `#5e4a7b` | `#6e3fa6` |
| Band hover | `#7b6b93` | `#8862b6` |
| Text | `#ece8f5` | `#1e1a2b` |
| Panel | `#1b1922` | `#f7f7f9` |
| Editor | `#14121a` | `#ffffff` |
