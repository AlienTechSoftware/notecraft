# NoteCraft brand

The written side of NoteCraft branding: colours, logo usage, and where
every brand asset lives. Image files live in `assets/brand/`; this folder
holds the words that go with them.

## Where things live

| What | Where |
|---|---|
| Logos, social cards, badges | `assets/brand/` |
| Banners | `assets/brand/banners/` (planned; see below) |
| Colour palette | `docs/brand/colors.md` |
| Logo usage | `docs/brand/logos.md` |
| Release notes | `docs/releases/` (one folder per version) |
| Release process | `docs/releasing.md` |
| AlienTech brand (Demelien mascot, AlienTech badge) | `AlienTechSoftware/alientech_software_web`, `brand/logo/` and `assets/` |

## Two brands, kept separate

NoteCraft and AlienTech are two different brands. The koala is NoteCraft's
mark; Demelien, the cyan alien, is AlienTech's mascot. The AlienTech badge
in the README credits AlienTech Software as the project's sponsor; the Try
NoteCraft! badge is the product's own badge. Do not use one brand's mark for
the other.

## Banners

Release banners belong in `assets/brand/banners/`, one file per release,
named `<version>-<description>.png`. The first banner, the 0.0.19 koala-frame
banner used for the Discord and Reddit announcements, is still to be added.
