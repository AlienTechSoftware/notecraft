NoteCraft に独自の同期はなく、アカウントもありません。ノートブックは小さなファイルの入ったフォルダーなので、ノートブックのフォルダーを同期ツールがすでに見ている場所に置いてください。OneDrive、Dropbox、Google Drive、iCloud Drive、Syncthing、ネットワーク共有、git リポジトリ。どれも NoteCraft を理解する必要はありません。ファイルをコピーするだけです。

なぜうまくいくか

  • ページごとに 1 ファイル。 ページの編集は小さなファイルをひとつ書き直すだけなので、2 台の機械が同じバイトに触れることはめったにありません。
  • アトミックな書き込み。 ページは一時ファイルに書かれ、名前を変えて古いものと置き換わります。同期クライアントが書きかけのページを見ることはありません。
  • 短く安全な名前。 フォルダー名は 64 文字まで、パスは 255 文字まで、Windows が拒む文字は決して書きません。
  • 競合コピーに気づく。 同期ツールがページの横に競合コピーを残すと、チェッカーが報告します。ファイルからチェック、またはターミナルで notecraft-cli check。

バックアップ

バックアップはフォルダーのコピーです。ほかに書き出すものはありません。

ページ履歴

History、Page Versions の順に開くと、このページの保存済みコピーを確認して復元 できます。削除したページ、セクション、セクショングループは History の Notebook Recycle Bin から復元できます。これらの機能はこの端末で動作し、ノートブック の別バックアップの代わりにはなりません。

扱わないこと

NoteCraft はページの 2 つの版を統合しません。同期ツールが競合コピーを作った場合は、 どちらの版を残すか自分で決めてください。
