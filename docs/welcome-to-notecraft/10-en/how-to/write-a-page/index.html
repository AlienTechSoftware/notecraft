Click in a line and type. The page is shown the way it reads: headings in heading type, bold and italic in their own look, code in a box, crossed out when it is done with. The marks that make them stay in the text but step back, so the words come first.

Equations

Type TeX between dollar signs: $E = mc^2$ inline, or a block of its own:

\int_0^1 x^2 \, dx = \tfrac{1}{3}

NoteCraft draws fractions, roots, sums, integrals, brackets and Greek letters itself. Anything it does not know stays visible as text rather than disappearing.

The ribbon

Home has the marks and the blocks, a Styles gallery and the Tags gallery. Insert has tables, pictures, files, links, equations, diagrams and today's date. View has full page, search, rule lines, zoom, the theme and the page source.

The page source

The file behind this page is one click away: the < > button beside the page. What you type in either one lands in the file. Use it for anything the editor does not do yet.
