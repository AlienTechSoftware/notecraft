NoteCraft has no sync of its own and no account. A notebook is a folder of small files, so put your notebooks folder where your sync tool already looks: OneDrive, Dropbox, Google Drive, iCloud Drive, Syncthing, a network share or a git repository. None of them has to understand NoteCraft. They copy files.

Why it works

  • One file per page. Editing a page rewrites one small file, so two machines rarely touch

the same bytes.

  • Atomic writes. A page is written to a temporary file and renamed over the old one, so a

sync client never sees a half-written page.

  • Short, safe names. Folder names are at most 64 characters, paths at most 255, and

nothing Windows refuses is ever written.

  • Conflict copies are noticed. When a sync tool leaves a conflicted copy beside a page,

the checker reports it: File, then Check, or notecraft-cli check from a terminal.

Backup

A backup is a copy of the folder. There is nothing else to export.

Page history

Open History, then Page Versions, to review and restore saved copies of this page. To recover a deleted page, section or section group, open History, then Notebook Recycle Bin. These tools work on this device and do not replace a separate backup of the notebook.

What is not handled

NoteCraft does not merge two versions of a page. If your sync tool makes a conflict copy, you decide which version to keep.
