阿拉伯语、希伯来语、波斯语和乌尔都语从右边读起。NoteCraft 就这样绘制它们：字母连写，一行从右边缘挂下来，混合两种方向的一行按 Unicode 算法排列，所以价格里的数字方向保持正确：

السعر 123 ريال

实现这一点的字体随应用一起提供，所以上面这一行在没有安装阿拉伯字体的机器上看起来也一样。希伯来语和印地语也有自带的字体：

שלום עולם

नमस्ते दुनिया

三种方向，三个控件

控件位置设置的内容
页面开始，然后方向整页的阅读方向。没有自己字母的一行跟随它
段落基本文本里的对齐菜单光标所在段落的阅读方向
片段方向组里的更多...选中文字的阅读方向，或者接下来输入的方向

页面方向是 NoteCraft 自己的设置；人们用过的那些应用没有这项设置，而用阿拉伯语写的笔记本需要它。

设置保存在哪里

在文本本身里。页面方向是 Markdown 页面前置元数据里的 dir: rtl，或 HTML 页面里的一个 meta 标签。段落方向是段首的一个不可见字符，Unicode 的从右到左或从左到右标记。两者在任何其他编辑器里都能保留。

这个笔记本的阿拉伯语、波斯语、乌尔都语和希伯来语分组全部从右到左书写。从起始页打开一个，比较一下。
