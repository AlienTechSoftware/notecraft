Write a diagram as Mermaid text in a fenced block. NoteCraft draws the block on the page in the current theme; open the page source with < > to edit the text.

Flowchart

flowchart TD
  Start[Write a note] --> Save{Saved?}
  Save -->|yes| Ready[Keep going]
  Save -->|not yet| Wait[Pause briefly]
  Wait --> Save

Sequence

sequenceDiagram
  Writer->>Page: Type a line
  Page->>Files: Save the page
  Files-->>Page: Saved
  Page-->>Writer: Keep writing
