이 페이지는 HTML 파일입니다. 이 섹션의 다른 페이지들은 Markdown 파일입니다. 둘 다 같은 방식으로 편집하며 페이지 위에서는 구별할 수 없습니다. 형식은 오른쪽 위, 저장 상태 옆에 표시됩니다.

형식파일알맞은 용도
HTML, 기본값index.html풍부한 배치, 다른 곳에서 온 페이지
CommonMark + GFMindex.md깔끔한 차이 비교와 병합, 파일 자체를 읽기

어디서 정해지나

  1. 페이지를 만들 때 고른 형식.
  2. 그 위의 섹션, 그룹, 노트북에 설정된 가장 가까운 형식.
  3. 전역 설정, 위쪽 막대의 기본 형식 상자.
  4. 내장 기본값, HTML.

설정은 새 페이지만 바꿉니다. 이미 있는 페이지는 자기 형식을 지키며, 그것은 파일 이름에서 보이므로 페이지를 읽는 데 설정은 필요 없습니다.

이 페이지의 원본 보기

페이지 옆의 < > 버튼을 누르세요. 파일 머리에는 페이지의 식별자와 날짜가 <meta name="notecraft:..."> 태그로 들어 있습니다. Markdown 페이지는 같은 것을 프런트 매터에 둡니다. NoteCraft는 <body> 안쪽만 편집합니다.
