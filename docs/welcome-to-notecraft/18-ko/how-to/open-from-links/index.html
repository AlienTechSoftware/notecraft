예정: NoteCraft를 여는 링크

NoteCraft는 브라우저, 이메일, 채팅 또는 다른 앱의 링크에서 노트북의 특정 페이지를 여는 기능을 제공할 예정입니다. 운영 체제는 notecraft: 링크 유형을 사용해 NoteCraft를 실행하고 열 페이지를 전달합니다. 운영 체제와 브라우저에 따라 앱을 열기 전에 확인을 요청할 수 있습니다.

이 기능은 아직 제공되지 않습니다. 현재 NoteCraft는 운영 체제에 notecraft:를 등록하지 않으며 외부 링크가 가리키는 페이지를 열지도 않습니다. NoteCraft 페이지 링크를 복사해도 지금 브라우저에서 열 수 있다는 뜻은 아닙니다.

링크 등록 계획

  • Windows 설치 프로그램: 설치 중 NoteCraft를 등록하고 제거할 때 등록을 해제합니다.
  • Windows 포터블 ZIP: 사용자가 직접 실행하는 별도의 NoteCraft 링크 등록 작업과 등록 해제 방법을 제공합니다. ZIP을 압축 해제하는 것만으로는 등록되지 않습니다.
  • macOS: NoteCraft 앱 번들에 링크 유형을 선언합니다.
  • Linux: 해당 링크 유형에 대한 데스크톱 앱 연결을 설치합니다.

등록은 운영 체제에 링크를 전달할 앱을 알려줄 뿐입니다. NoteCraft는 해당 노트북과 페이지를 찾고, 이미 실행 중일 때 링크를 처리하며, 노트북이나 페이지를 찾지 못하면 그 사실을 명확히 알려야 합니다. 이 과정도 모두 계획된 기능에 포함됩니다.
