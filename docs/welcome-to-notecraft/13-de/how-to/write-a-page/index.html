Klicken Sie in eine Zeile und tippen Sie. Die Seite wird so angezeigt, wie sie gelesen wird: Überschriften in Überschriftenschrift, fett und kursiv mit ihrem eigenen Aussehen, Code in einem Kasten, durchgestrichen, wenn es erledigt ist. Die Zeichen, die das bewirken, bleiben im Text, treten aber zurück, damit die Wörter vorne stehen.

Formeln

Tippen Sie TeX zwischen Dollarzeichen: $E = mc^2$ in der Zeile oder als eigener Block:

\int_0^1 x^2 \, dx = \tfrac{1}{3}

NoteCraft zeichnet Brüche, Wurzeln, Summen, Integrale, Klammern und griechische Buchstaben selbst. Was es nicht kennt, bleibt als Text sichtbar, statt zu verschwinden.

Das Menüband

Start enthält die Zeichen und Blöcke, eine Formatvorlagen-Galerie und die Markierungs-Galerie. Einfügen enthält Tabellen, Bilder, Dateien, Links, Formeln, Diagramme und das heutige Datum. Ansicht enthält Ganzseitenansicht, Suche, Linien, Zoom, das Design und den Seitenquelltext.

Der Seitenquelltext

Die Datei hinter dieser Seite ist einen Klick entfernt: die Schaltfläche < > neben der Seite. Was Sie in einer der beiden tippen, landet in der Datei. Nutzen Sie ihn für alles, was der Editor noch nicht kann.
