# NoteCraft 0.0.3

> Historical release record. NoteCraft was an early alpha and Windows x64 was the only
> tested release platform at this point.

## Highlights

- Untitled pages and related page-title improvements.
- RTL and clipboard improvements.
- Fixed a `SystemTime`/`Instant` panic in the WASM UI path.

## Known release guidance

- Keep backups of notebooks because the folder format may still change.
- The installer and uninstaller do not touch notebooks.
- See [`docs/gaps.md`](../../gaps.md) for known limitations.

Original release: [v0.0.3 on GitHub](https://github.com/AlienTechSoftware/notecraft/releases/tag/v0.0.3).
