# NoteCraft 0.0.4

![NoteCraft 0.0.4 release notes](NC.0.0.4.jfif)

## Feature summary

- OneNote notebook-folder import with recursive notebooks, section groups, sections, and nested pages.
- `.one` file import through the OfficeIMO bridge.
- Windows-style collision avoidance for repeated imports: `Name (1)`, `Name (2)`, and so on.
- Cancellable import progress dialog.
- Shared themed modal surfaces with painted title bands and visible accent borders.
- Default-theme import walkthrough screenshots for HTML and CMGFM demo notebooks.
- OfficeIMO credit and MIT license links in About.
- Scratch demo drift detection with explicit replacement approval.
