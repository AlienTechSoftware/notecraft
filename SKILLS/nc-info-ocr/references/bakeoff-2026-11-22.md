# Bake-off: ocrs 0.14 on the POC pictures (2026-11-22)

Measured on a development machine (Windows, release build), one run per picture. The pictures are
the POC notebook's test set (private; not in the repository). Times are wall-clock for one call to
`read_image`, including decoding.

## Setup

- Engine: `ocrs` 0.14.0 through `notecraft-ocr` (`OcrsReader`).
- Models: official ONNX files from the ocrs model host: `text-detection.onnx` (2.5 MB) and
  `text-recognition.onnx` (9.7 MB). Loaded by `rten` 0.28 with its ONNX reader.
- Not used: Hugging Face RTen conversions (fragmented output) and PP-OCRv5 (not yet tested).
- Load time for both models: about 6 ms.

## Results

| Picture | Lines | Time | What came out |
|---|---|---|---|
| receipt (printed, mixed bold, 640 x 420) | 12 (after joining rows: 8 printed rows) | 154 ms | Every word right. The engine split items from prices; the joining step put them back on one row, matching the reference text |
| scan (scanned page) | 5 | 130 ms | All 5 lines right |
| chart (bar chart) | 6 | 109 ms | Title right; some axis labels right, others split |
| whiteboard sketch | 4 | 122 ms | Fragments; not expected to read |
| Arabic receipt | 13 | 133 ms | Arabic lines are garbage. The English prices read correctly |

## Acceptance criteria on this engine

| # | Result |
|---|---|
| A1 reading order (receipt vs reference) | Passes after row joining |
| A2 box and confidence | Passes with confidence optional (no confidence from ocrs) |
| A3 boxes inside the picture | Passes after clamping (boxes were up to 3 px outside) |
| A4 unchanged picture not re-read | Passes (companion job, FNV-1a hash) |
| A5 changed picture re-read, companion replaced | Passes |
| A9 Arabic | Fails: the English recogniser cannot read Arabic |

## What the measurement does not show

- Memory use and speed on phones were not measured.
- Only one run per picture; no variance.
- PP-OCRv5 was not run on the same pictures, so this is not a comparison of engines yet.
- The accuracy numbers above are by reading, not by a scored reference beyond A1.
