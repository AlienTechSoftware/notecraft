## C. Generators and their outputs

| Tool | Output | Committed? |
|---|---|---|
| `cargo xtask screenshots` → `readme-screens.jsonl` → `ui_shot` | `docs/images/*.png` (section A) | yes |
| `crates/ui-egui/examples/ui_shot.rs` | any picture a script asks for | the code only |
| `crates/ui-egui/tests/icons_visual.rs` (with `NOTECRAFT_UI_VISUAL_DIR`) | before, after and difference pictures per icon | no, written to a folder you choose |
| `crates/ui-egui/tests/ui.rs` failing visual tests | `*.diff.png` and `*.new.png` next to the test picture | no, git-ignored |
| `scripts/capture-window.ps1` | a picture of a window on the desktop (Windows only) | the code only; not used for shipped pictures |

## D. Images that are not screenshots

`assets/demo/banner-*.png` are banners drawn or copied for the Welcome notebook. They are listed in
`ATTRIBUTION.md` with their source. They are not generated by any script in this repo.

## How to keep this current

- When you add a `shot` line, add a row to section A and a README reference if it is shown.
- When you regenerate a picture, change its "Checked by eye" column only after you have looked
  at it.
- When a generator script changes path, update its row here.
- Run `cargo xtask screenshots` and then `git status` after any UI change. Every picture that
  changed must be named in the commit message.
